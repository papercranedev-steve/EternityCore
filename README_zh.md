# EternityCore

**EternityCore** 是基于 [vMaNGOS](https://github.com/vmangos/core)（魔兽世界香草时代 1.12.1）的开源单机向分支，致力于打造**接近真人水平的智能 AI 队友（PartyBot）**，让单机玩家也能像网游一样组队升级、刷装备、攻略副本。

> [!NOTE]
> 除 AI 队友与单机体验相关改动外，所有底层世界模拟、数值体系、任务与副本脚本均保留 **vMaNGOS** 原版机制。EternityCore 的核心改动集中在 **Commander AI 架构**（`src/game/PlayerBots/Commander/`）。

---

## 核心特性（已实现）

### 四层 Commander AI 架构

EternityCore 用实时协同的决策流水线替代了传统脚本式机器人循环：

1. **局势感知层（眼睛）**
   - 直接读取服务端精确仇恨表（`ThreatManager`）与坦克安全余量（近战 `110%` / 远程 `130%`）。
   - 识别怪群（`creature_groups` + 距离）、巡逻路径与安全引怪边界。
   - 预测开怪连锁援助与低血量怪物逃跑引怪风险。
   - 自动分析怪物技能档案（可打断施法、危险 AoE / 沉默范围）以及队伍实时承伤。

2. **团队指挥层（大脑）**
   - **自动职责分工**：根据天赋与装备评分自动划分坦克、治疗与输出职责。
   - **集火与转火分配**：优先击杀高威胁法系/治疗怪，协调转火与逃跑拦截。
   - **仇恨均衡与团队救援**：多目标仇恨维护、嘲讽与消仇恨（渐隐/假死）协调，以及全队保命技能统筹（套盾、盾墙、圣疗等，避免重复交技能）。
   - **打断链与控制分工**：分配主打断/备用打断，以及变形术/闷棍/冰冻陷阱等控制目标，并统一拦截会打醒控制的误伤。
   - **开怪规划与 AoE 爆发**：支持远程开怪、卡视角拉怪、准备检查、AoE 阶段协同（如冰环/套盾配合暴风雪），以及防团灭撤退与灵魂石/复生自救逻辑。

3. **个人行为与仲裁层（小脑）**
   - 基于统一的 **“收益 − 代价”** 打分仲裁器，在每次 AI Tick（`PartyBot.Commander.BotUpdateMs`，默认 `200 ms`）中做出最优选择。
   - **智能治疗规划**：结合实测承伤、技能 HPS/HPM 与法力预算动态挑选治疗技能与等级，支持读条中途过量/OT 取消（`CastWatch`）。
   - **战术走位与站位场**：基于位置场打分实现坦克拉怪站位、治疗身后安全站位、近战绕背、远程避怪安全线及巡逻躲避。
   - **长冷却与宠物管理**：爆发/保命大招协同，以及猎人宠物技能与自动嘲讽切换管理。

4. **5 人本首领专项机制**
   - 已针对部分经典 5 人本首领战进行专项机制适配：
     - **艾德温·范克里夫**（死亡矿井）
     - **麦克尼尔·瑟玛普拉格**（诺莫瑞根——炸弹与按钮处理）
     - **血色指挥官莫格莱尼 & 大检察官怀特迈恩**（血色修道院）
     - **黑暗院长加丁**（通灵学院）
     - **祖尔法拉克百人斩台阶**

## 开发里程碑与路线图

EternityCore 将按阶段逐步推进，最终构建完整的单机魔兽陪伴体验：

- [x] **阶段 1：高智商副本战斗 AI** *（核心已完成，持续打磨中）* —— 实现 5 人本不团灭，像真人一样处理仇恨、治疗、控制、打断与走位。
- [~] **阶段 2：野外组队练级与全 5 人本 Boss 机制覆盖** *（野外组队打怪基础可用，Boss 机制持续补充中）* —— 确保所有 5 人副本及特殊机制均可稳定通关。
- [ ] **阶段 3：玩家感知（Player-Aware）与前序团本 AI** —— 让 AI 在组队时以玩家为中心，适应玩家节奏并提供情绪价值；同时适配前 3 个经典团队副本。
- [ ] **阶段 4：自主冒险行为** —— Bot 支持拾取物品、接取与提交任务、自动点天赋以及专业采集。
- [ ] **阶段 5：Bot 养成与渐进披露体系** —— 设计伴随等级提升逐步解锁功能与特性的成长体系。
- [ ] **阶段 6：好感度、默契值与特质系统** —— 引入好感度、战斗默契度与 Bot 个人特质（Quirk）。
- [ ] **阶段 7：接入大语言模型（LLM）** —— 赋予 Bot 自然语言互动能力与真正的“活人感”。

## 快速开始

### 1. 服务端配置（`mangosd.conf`）

Commander AI 默认开启，相关核心配置项如下：

```ini
PartyBot.Commander.Enable = 1
PartyBot.Commander.BotUpdateMs = 200
PartyBot.Commander.PerceptionMs = 200
PartyBot.Commander.DisabledModules = ""
```

### 2. 常用游戏内指令

在游戏内可通过 `.partybot ai` 系列指令控制和查看 AI 状态：

| 指令 | 说明 |
|---|---|
| `.partybot ai` | 查看 Commander 状态、更新间隔与模块数量 |
| `.partybot ai on \| off` | 全局开启 / 关闭 Commander AI |
| `.partybot ai say [on\|off]` | 开启 / 关闭 Bot 在队伍频道播报决策 |
| `.partybot ai pull [now\|cancel]` | 准备检查后规划并拉取目标或最近的怪群 |
| `.partybot ai clear [r] [n]` | 连续清理半径 `r` 码内的怪群（每次最多 `n` 只） |
| `.partybot ai retreat [stop]` | 命令全队停手并撤退至安全点或副本门口 |
| `.partybot ai plan` | 查看当前团队计划（集火、打断、开怪状态） |
| `.partybot ai threat` | 查看当前敌人的实时仇恨表与 OT 余量 |
| `.partybot ai stats [reset]` | 查看 AI Tick 耗时与 CPU 占用统计 |

### 3. 支持客户端与编译

支持客户端版本与编译流程与原版 vMaNGOS 一致（支持 `1.12.1.5875+` 至 `1.5.1.4449`，使用 CMake + C++17 编译）。环境搭建与数据库导入请参考上游 [vMaNGOS Wiki](https://github.com/vmangos/wiki)。
